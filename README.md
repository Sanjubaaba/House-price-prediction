# House-price-prediction

This project predicts house prices using **12 machine learning algorithms** (including linear, polynomial, tree-based, and SVM models) through a complete **data science pipeline**: First, we **preprocess** the data by handling missing values, encoding categories, and engineering new features. Next, we **split and scale** the data, then train and evaluate each model using **RMSE and R² scores**. The best model (**Random Forest**) is **fine-tuned** via hyperparameter optimization, and its **feature importance** is analyzed. Finally, we generate **price predictions** on test data, ready for submission. The implementation balances **comprehensiveness** (covering all requested algorithms) and **practicality** (focusing on regression-appropriate techniques).
